## Module Boundaries

- **Core and compute modules import no Qt.** Verified by import scan: PySide6 is imported at module level only in `gui/*`; `__main__.py` (lines 59-60, 158), `gui_validation.py`, and `gl_software_win32.py` import PySide6 inside functions. `gl_software_win32.py` imports PyOpenGL at module level and PySide6 only inside `_qt_software_library()` (line 18) to locate Qt's software OpenGL DLL.
- **Dependency direction:** `gui` → (`data`, `local_data`, `user_store`, `models`, `ground_track`, `gl_platform`; function-local: `manual` (`gui/window.py:290,709`, `gui/manual_input.py:167`), `orbit` (`window.py:724`), `numerical` (`window.py:727`), `export` (`window.py:810`)) ; `gui_validation` → (`models`, `orbit`, `gl_platform`, `gui.window`; `gui_validation.py:37,38,152,160`) ; `numerical` → (`manual`, `orbit`, `models`) ; `orbit` → `models` ; `data` → (`models`, `cache_lock`, `validation`) ; `local_data` → (`models`, `tle`, `validation`). `models` imports nothing from the package.
- **Immutability contract:** results cross the thread boundary as frozen dataclasses; arrays are made read-only in `models._readonly_array`; JSON payloads are frozen with `freeze_json` (`MappingProxyType`).
- **Threading contract:** network and long computations run inside `TaskWorker`; tasks receive `(progress, cancel)` callables and raise `CancelledError` on cancel.
- **Astropy global state:** `orbit.py` serializes `iers.conf` changes and IERS table use with `_EARTH_LOCK` (`orbit.py:26`).
